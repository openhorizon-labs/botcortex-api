# botcortex-api

Cloud services for [BotCortex](https://github.com/openhorizon-labs/botcortex):
identity now; licensing, relay, and hub later. **Bun + Hono + Better Auth +
Drizzle**, with Supabase as the Postgres.

The on-robot runtime never depends on this service — an expired or unreachable
api can never stop motion or local execution.

## Layout

| Path | What it is |
|---|---|
| `src/index.ts` | Bun entrypoint |
| `src/app.ts` | Hono app: CORS, `/health`, `/api/auth/*` (Better Auth), `/api/me` |
| `src/auth.ts` | Better Auth config — email+password, Drizzle adapter |
| `src/auth-schema.ts` | Generated by `bun run auth:schema` — do not hand-edit |
| `src/db.ts` | postgres-js → Supabase pooler (`prepare: false`) |
| `drizzle/` | SQL migrations (`bun run db:generate`) |
| `tests/` | Full auth round-trip on in-memory Postgres (PGlite) — no network |

## Development

```bash
bun install
cp .env.example .env   # fill DATABASE_URL + BETTER_AUTH_SECRET
bun test               # runs against PGlite, no Supabase needed
bun run dev            # http://localhost:8787
```

Schema changes: edit `src/auth.ts` → `bun run auth:schema` → `bun run db:generate`
→ apply the new `drizzle/*.sql` to Supabase.
